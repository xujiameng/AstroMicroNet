# AstroMicroNet

AstroMicroNet identifies and analyzes core–periphery organization in astrocytic calcium microdomain networks. This repository contains the software, simulation materials, analysis results, and ROI masks accompanying the study.

| Folder or file | Contents and purpose |
|---|---|
| `AstroMicroNet_software/` | MATLAB graphical interfaces, the Python analysis backend, and a synthetic network example for core identification and network analysis. |
| `validation/` | Simulated waveforms, reference outputs, and scripts for regenerating synthetic inputs and checking algorithm results. |
| `supplementary/` | Supplementary figures, numerical source data, simulation networks, analysis parameters, and plotting and method-comparison scripts. |
| `original_ROI_masks/` | Binary ROI masks and identifier mappings for 13 astrocytes, linking microdomains to their original records. |
